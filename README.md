# 👾 🟡 👻 Pacman

🕹️ This project is a full recreation of the classic **Pac-Man** game developed in **Java** using **AWT** and **Swing** libraries. It features core gameplay mechanics such as player movement, ghost AI, collectible pellets, and game-over logic — all implemented from scratch. The goal was to explore object-oriented programming and GUI development in Java while recreating a nostalgic arcade experience.

## 💡 Modules Overview 

- Java (JDK 21 or later)
- AWT (Abstract Window Toolkit)
- Swing (Java Foundation Classes)

## 🎲 Main features
- Responsive 2D movement with keyboard controls
- Simple enemy AI with chase behavior
- Score tracking and win/lose conditions
- Custom-designed UI with classic Pac-Man visuals

_Run the project locally by following the steps below 👇_

1. Install JDK (21 or later) using some IDE
2. Clone the repo
   ```sh
   git clone https://github.com/rian-fuzinelli/pacman-java.git
   cd pacman-java
   ```
